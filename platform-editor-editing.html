Editing a Manifest

Open a manifest

1.Choose File > Open... and select the <firmware>_platform.json file, or

2.choose File > Open Folder..., pick the folder (for example the run directory), and click a file in the Manifests pane.

If the file is not valid JSON the editor says where it stopped reading and opens nothing.

 

Change a field

1.Select the item in the tree.

2.Change the value in the Properties pane and press Enter, or move to another field.

3.Check the Issues pane; the checks run after every change.

A value that does not fit the field (text in a number field, a hex field without 0x) is refused, the field keeps its old value, and the status bar gives the reason.

 

Add a disk or CD-ROM to a controller

1.Select the controller (for example pka_53c810 or cypress_ide) in the tree.

2.Click + Device and choose Virtual Disk or Virtual CD-ROM.

3.The editor adds a row at the next free address: on a 53C810 SCSI controller targets 0 to 6 (7 is the controller itself); on IDE channel 0 master, channel 0 slave, channel 1 master, channel 1 slave.

4.Select the new row and set media to the image file name.

 

A new SCSI disk gets the drive model EMulatR-4G. A SCSI disk's model must be one of the drive models in disk_types.json, and the image must be at least that model's size, or the emulator will not attach it. If the controller has no free address the editor says "Bus full". To add several disks at once, with drive models and new image files, use the Configure wizard.

 

Duplicate or delete an item

1.Select the item and click Duplicate or Delete.

2.Delete asks for confirmation.

 

Some items cannot be removed or copied:

•The IIC devices the emulator requires (addresses 0x70, 0x72, 0xA2, 0x40, 0x42 and 0x9E) cannot be deleted.

•A device the emulator has only one of -- the 53C810 SCSI controller, the DE500 network controller, the IDE and ISA bridge functions -- cannot be duplicated (V-44).

 

Save

File > Save writes the manifest safely: the new text goes to a temporary file first and replaces the old one only when complete, and the previous version is kept as <name>.bak. File > Save As... saves under a new name. If you close or open another file with unsaved changes, the editor asks first.

 

Make a new system from a shipped manifest

1.Open the platform's manifest, for example ds20_v7_3_platform.json.

2.Choose File > Save As... and give the new system's name.

3.Choose Tools > Configure... and add its disks, CD-ROM and MAC address.

4.Save.

Keep the new file's name ending in _platform.json, and point the launcher or the command line at it when you run the system.
