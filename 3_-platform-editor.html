3. Platform Editor

The Platform Editor (platedit_wx.exe) is the desktop application for creating, checking and changing an EMulatR platform manifest: the <firmware>_platform.json file, for example ds20_v7_3_platform.json, that tells EMulatR which devices the emulated machine has.

 

What the manifest holds

A platform manifest is a JSON file with three kinds of content:

•IIC devices (iic_devices): the system bus devices the firmware reads at power-up -- status registers, the FRU EEPROMs that show fru reports, the NVRAM. The set of IIC devices is fixed per platform; their contents (manufacturer, model, part number, serial) can be edited.

•PCI devices (pci_devices): each device with its location (hose, bus, slot, function), identity (vendor, device, class code) and model, for example the ncr53c810 SCSI controller or the de500 network controller.

•Storage (storage under a disk controller): each disk, CD-ROM or other unit, with its address on the controller, its drive model and its media (an image file or an ISO).

 

The rule for what belongs in the manifest: anything that two machines of the same model can differ in is configuration and lives in the manifest (disks, media, a network MAC address). Anything fixed by the hardware design is architecture and is built into EMulatR (interrupt wiring, which chips a board has).

 

When to use it

•To add disks or a CD-ROM to a system, or change the image files they use.

•To give a system its own network MAC address.

•To check a manifest before running it: the editor shows every problem it finds (the Issues pane) and marks the device it concerns.

•To make a new system: open the platform's shipped manifest, save it under a new name, then use Configure.

 

What the editor never does

•It never reformats a file. An unchanged manifest saves byte-for-byte identical; editing one field changes only that field. Structural changes (adding or deleting a device) rewrite only the list they touch.

•It never overwrites a disk image, and Undo never deletes one.

•It never writes a device the emulator cannot run: virtual tape, a second SCSI controller and a second network controller are refused (see Validation Messages).
