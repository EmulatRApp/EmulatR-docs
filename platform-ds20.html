AlphaServer DS20

The DS20 is a dual-processor Tsunami system. It is the most complete model: it boots OpenVMS V8.3 to Username:, and EMulatR installed V8.3 on it from the emulated CD. It is also the benchmark for performance work; boot-to-Username: time on the DS20 is the measure each release is judged by.

Running a DS20

cd /d/EMulatR/project && v2.1/tools/EMulatR_launch.sh ds20 run -- --no-autoload --autosnapshot off

For the fastest boot, use the Release build. The JIT is on by default; set EMulatR_JIT=off to run without it.

 

Status

•SRM console to P00>>> with every device present.

•OpenVMS V8.3 boots from dka200 to Username:.

•OpenVMS V8.3 installs from the ISO on dqa1, then boots and configures (DECnet, DTSS, TCP/IP, DECdtm).

 

SMP considerations

The DS20 supports two CPUs; EMulatR runs one. The platform manifest pins the CPU count to one, and the SRM console reports a single CPU in the active set. Running more than one CPU (SMP) is planned for release 2.3, with every CPU on one host thread so that a run stays deterministic and repeatable. A threaded mode, one host thread per CPU, follows in release 3.1.

 

The DS20 is the first SMP target. What changes when its second CPU starts:

•CPU start-up. The console starts the second CPU through its secondary start-up path and the HWRPB per-CPU slots. The number of slots and the number of CPUs the chipset reports must come from the same count.

•Interlocked memory. LDx_L / STx_C reservations must be honored across CPUs, not just within one.

•Interrupts. Each CPU has its own interrupt mask and summary in the Cchip, and inter-processor interrupts go through the Cchip.

•Per-CPU state. Translation buffers, cycle counters, reservation state and the performance counters become per-CPU.

•Idle and time skipping. Idle fast-forward can only skip when every CPU is idle.

•Speed. With both CPUs on one host thread, each runs at about half of today's rate. SMP buys the multiprocessor code paths, not throughput.

•Snapshots. A snapshot must carry every CPU's state, so the snapshot format changes.
