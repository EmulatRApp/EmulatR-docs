Glossary

Placeholders, terms and acronyms used throughout this guide.

Placeholders

A name in angle brackets stands for a value you substitute: type the value, not the brackets. <stem>.rom for the DS20 firmware is ds20_v7_3.rom.

Placeholder

Stands for

Example

See

<stem>

The firmware stem: the firmware image's file name without its extension. It names every file that belongs to that firmware, and its first word selects the machine model (it overrides the ini's [System] model). A log written with no firmware in use is named emulatr instead, unless EMULATR_LOG_STEM sets a stem.

firmware/ds20_v7_3.exe gives ds20_v7_3, hence ds20_v7_3.rom, ds20_v7_3_platform.json, logs/ds20_v7_3_boot_20260921_101500.log

Firmware Images: .exe and .rom

<firmware>, <firmware-stem>, <platform>

The same as <stem>. <platform>_platform.json is the platform manifest named for its firmware.

ds20_v7_3_warp.json, ds20_v7_3_platform.json

<firmware>_warp.json -- Calibrated-Delay Census

<model>

The machine model in lower case -- the first word of the stem: ds10, ds20, ds25, es40 or es45.

<model>_v7_3_platform.json is ds20_v7_3_platform.json

Current Platform Support

<plat>

The platform argument the tools scripts take: a model name, or a named run environment.

emulatr_launch.sh ds20

Tools Script Reference

<run-dir>, <run>

The run directory: the folder EmulatR is started from. It holds the firmware, configuration and platform manifests, and receives the logs, snapshots and flash NVRAM. In a build tree it is out/build/<tree>-<config>/run/; for an installed kit it is the system's profile directory.

<run-dir>/tools/, <run-dir>/logs/

Running from a Run Directory, Run-Directory Contents

<profile>, <your profile directory>

A named system's profile (run) directory, chosen when the system is created in the Launcher -- anywhere you own, for example under Documents, and never under Program Files. It holds that system's Emulatr.ini, disks, logs and flash NVRAM.

<profile>\logs\run_launch_*.log

Configuring a System with the Launcher

<tree>

The source tree a developer build comes from: v2.0 (current) or v5.

out/build/v2.0-release/run/

Building from Source

<config>

The build configuration: release, relwithdebinfo or debug. The EMULATR_DIAG_* diagnostic facilities exist only in relwithdebinfo and debug builds.

out/build/v2.0-relwithdebinfo/run/

Building from Source

<project>

The root of the source tree, in developer instructions.

<project>/tools/

Running from a Run Directory

<purpose>

A short word naming what a log or trace is for, chosen by the tool or script that writes it.

boot, showdev, atapiwire

Tools Script Reference

<ts>, <timestamp>, <YYYYMMDD>, <HHMMSS>

The local date and time the file was created, written YYYYMMDD_HHMMSS.

20260921_101500

<port>

The TCP port of a system's SRM console. The default is 10023; give every system that runs at the same time its own port.

127.0.0.1:10023

TCP Console Overview

<device>

An SRM console device name.

dka0, dqa1, ewa0

Guest Boot

<var>, <value>

An SRM environment variable and the value to give it.

set auto_action halt

SRM Environment Variables

<adapter>

The Windows name of a host network adapter, as Network Connections shows it.

Ethernet 2

Naming the Host Adapter (EMULATR_NET_ADAPTER)

<name or description substring>, <description-substring>

Part of a host adapter's description, as EMULATR_NET_ADAPTER accepts it.

I219

Naming the Host Adapter (EMULATR_NET_ADAPTER)

<guest-ip>

The IP address configured inside the guest operating system.

4.9 Networking (EWA0)

<pa>, <va>, <pc>, <addr>, <address>

A physical address, a virtual address, a program-counter value, or any address -- in hexadecimal.

0x80130000040

<subsys>, <csv>

A logging subsystem name; a comma-separated list of them.

--log-verbose <subsys>

Logging Subsystems (EmulatR)

<version>, <stage><major>.<variant>-<build>

The kit version, and its parts: the stage letter (X experimental, T field test, V released), the major and variant numbers of the line, and the build number.

T2.0-16: stage T, line 2.0, build 16

EmulatR Version Numbering and Release Stages

<N>, <n>, <count>, <bytes>

A number; a count; a size in bytes.

--mem 1073741824

<path>, <dir>, <file>, <name>, <s>

A file path, a directory, a file, a name, a string.

<CR>, <Return>, <Enter>

Press the Enter key. A key name in angle brackets is a key to press, not text to type.

 

Terms and acronyms

Term

Meaning

See

21143 (Tulip)

DEC's PCI Fast Ethernet controller chip; the chip on the DE500-BA that EmulatR models as EWA0.

DE500 Ethernet (21143 Tulip)

21264 / EV6 (EV67)

The Alpha CPU implementation EmulatR emulates; EV67 is the later 21264A.

21272 / Tsunami / Typhoon

The core-logic chipset: Cchip (control), Dchip (data), Pchip (PCI).

Tsunami \ Typhoon

AARM

The Alpha Architecture Reference Manual.

Alpha AXP

Digital's 64-bit RISC architecture. EmulatR models the 21264 (EV6) generation.

What is EmulatR

ARP

Address Resolution Protocol: finds the MAC address that owns an IP address on the local network.

ASN

Address Space Number, the tag distinguishing per-process translations.

AST

Asynchronous System Trap: OpenVMS's mechanism for running a routine in a process when an event completes.

ATA / IDE

The PC disk interface; IDE is Integrated Drive Electronics.

IDE Devices

ATAPI

The packet command set for optical / removable devices on an IDE channel.

ATAPI Devices

.axpsnap

An EmulatR machine-state snapshot file, written to snapshots/. The newest is restored at start-up unless --no-autoload is given.

Snapshot Operations

Badge (MHz badge)

The CPU speed the SRM banner prints. EmulatR shows the previous run's measured effective speed, marked ~.

WARP Variants and Cycle-Accounting for Reported CPU Speed

BAR

Base Address Register: the PCI configuration register that places a device's registers in the address map.

Block execution

EmulatR's normal execution model: runs of straight-line instructions execute from a cache of decoded blocks.

Block-Execution

Box

A functional execution domain in EmulatR: IBox (control flow), EBox (integer), FBox (floating point), MBox (memory), CBox (cache / predict), PalBox (privileged).

Cchip / Dchip / Pchip

The three 21272 components: system control and memory arbitration, the data path, and the PCI host bridge.

Chipset

CDB

Command Descriptor Block: one SCSI command as sent to a device.

5.7 SCSI

CSC

Cchip System Configuration register: the 21272 register holding the chipset's configuration -- queue limits and timing, with its low byte taken from the Cchip's configuration pins at power-up (21272 HRM 10.2.2.1).

Tsunami \ Typhoon

CSERVE

The PALcode call that is the gate between the SRM console and PALcode (CALL_PAL CSERVE).

Reset into Secondary Boot (CSERVE START Handoff)

CSR

Control and Status Register.

CY82C693

The Cypress PCI-to-ISA south bridge of the DS10 and DS20 (also the IDE / ATAPI controller and SuperIO).

CY82C693

DCL

Digital Command Language: the OpenVMS command interpreter (the $ prompt).

DE500 (DE500-BA)

DEC's PCI Fast Ethernet adapter, built on the 21143; EmulatR's EWA0.

DE500 Ethernet (21143 Tulip)

DECnet

Digital's network architecture: Phase IV, and Phase V (DECnet-Plus, based on OSI).

4.9 Networking (EWA0)

DMA

Direct Memory Access: a device transfers data to or from memory without the CPU moving it.

dqa / dka / dva / ewa

SRM device names: IDE / ATAPI, SCSI, floppy, and Ethernet respectively.

Guest Boot

DRIR / DIM

The Cchip's Device Raw Interrupt Request and Device Interrupt Mask registers.

Chipset

DS10, DS20, DS25, ES40, ES45

The AlphaServer models whose firmware EmulatR runs. Support differs by model.

Current Platform Support

DSSI / SDI

Digital Storage Systems Interconnect; Standard Disk Interconnect -- DEC storage buses.

Storage Interconnect and Fabric

DTSS

Distributed Time Synchronization Service: keeps the clocks of networked OpenVMS systems in step.

EWA0

The guest's first Ethernet device: ewa0 at the SRM console, EWA0: in OpenVMS.

4.9 Networking (EWA0)

Execution mode: ISP / silicon (REAL_HW)

ISP is DEC's Instruction-Set-Processor engineering virtual model: the firmware skips the real-hardware timing and probe steps. Silicon (REAL_HW) takes the path real hardware takes. The ES40 and ES45 manifests bind silicon.

Platform Execution Mode: ISP (Engineering-Virtual) vs Silicon (REAL_HW)

GCT / FRU

The firmware's Configuration Tree and Field-Replaceable-Unit data, built during power-up.

grain

A single per-opcode leaf function that implements one instruction's semantics.

grainFactoryLib

HBA

Host Bus Adapter: an adapter that connects a storage bus, such as SCSI, to PCI.

5.7 SCSI

HRM

Hardware Reference Manual: DEC's documentation for a chip or system.

HWRPB

The Hardware Restart Parameter Block, the firmware-to-OS hand-off structure.

HWRPB Key/Value Offset Map

IIC (I2C)

The inter-IC serial bus the firmware probes for FRU and model-identity devices.

Model Badging: SRM Platform Identity from an IIC Discriminator Device

IMB

Instruction Memory Barrier (CALL_PAL IMB): makes instruction fetch see newly written code.

IPI

Interprocessor Interrupt: one CPU interrupting another.

SMP (MultiProcessor) Design

IPL

Interrupt Priority Level.

IPR

Internal Processor Register, accessed in PAL mode via HW_MTPR / HW_MFPR.

IRQ

Interrupt Request: an interrupt line or its number.

ISA

Industry Standard Architecture: the legacy bus behind the south bridge (serial and parallel ports, keyboard, floppy, TOY clock).

ISO image

A CD image file (.iso) attached to the guest as a CD-ROM.

Booting/Configure A New OpenVMS Instance from an ISO

ITB / DTB

The instruction and data Translation Buffers (the EV6 TLBs).

Addressing & TLB

kseg

The EV6 superpage region where a virtual address maps directly to physical (no page table).

KZPBA

DEC's PCI UltraSCSI adapter.

SCSI Devices

LANCP

The OpenVMS LAN Control Program (MC LANCP), which shows and sets LAN device parameters and counters.

4.9 Networking (EWA0)

LAST

Local Area System Transport: the protocol an InfoServer uses to serve disks and CDs.

LAT

Local Area Transport: DEC's terminal-server protocol.

LBA

Logical Block Address: a block number on a disk or CD.

LFU / UPD>

The Loadable Firmware Update utility and its prompt, used to update firmware in flash.

Firmware Update Utility (LFU)

M1543C / M5229

The ALi PCI-to-ISA south bridge of the ES40 and ES45, and its IDE function.

ALi M1543C South-Bridge Interface

MAC address

The 48-bit hardware address of an Ethernet interface. Under DECnet Phase IV it is set from the node address.

MC146818

The real-time clock chip that provides the TOY clock.

Time-of-Year Clock (TOY)

MMIO

Memory-mapped I/O: device registers reached at physical addresses.

MOP

Maintenance Operation Protocol: DEC's protocol for booting and remote console over a LAN.

MSCP

Mass Storage Control Protocol: serves disks between OpenVMS cluster members.

Named system

A machine defined in the Launcher: its name, platform, profile directory and settings.

Configuring a System with the Launcher

Npcap

The Windows packet-capture driver EmulatR uses to reach a real network. It is installed with Wireshark.

4.9 Networking (EWA0)

NVRAM

The non-volatile store holding the SRM environment variables -- the flash image <stem>.rom, maintained only by the running instance.

Firmware Images: .exe and .rom

NXM

Non-eXistent Memory: a physical access above the configured RAM limit.

OCP

Operator Control Panel: the front-panel display and buttons.

OPCDEC

The reserved-opcode fault, raised for an instruction the CPU does not implement.

OSF/1

The original name of Tru64 UNIX; its PALcode is one of the two PALcode personalities.

PALcode

Privileged Architecture Library code: the low-level routines (OpenVMS and Tru64 personalities) that implement privileged operations.

PALcode Platform Bases

PC264

The 21264 platform family, in DEC's SRM sources, that the DS10 and DS20 firmware belongs to.

PCI

Peripheral Component Interconnect: the I/O bus behind the Pchip.

PERROR

The Pchip's PCI error register.

Tsunami Error Chain (PERROR / No Devsel)

PIC

Programmable Interrupt Controller (8259-compatible, in the south bridge).

PIO

Programmed I/O: the CPU moves every word itself (compare DMA).

Platform manifest

The <stem>_platform.json file that declares a machine's devices, storage and execution mode.

Platform Identity & Memory Geometry

PTE / PTBR / VPTB

Page Table Entry; Page Table Base Register; Virtual Page Table Base.

Addressing & TLB

PVD

Primary Volume Descriptor: the ISO-9660 block at LBA 16, identified by CD001, that describes a CD's file system.

ISO-9660 PVD (CD001)

RPCC

The Alpha cycle-counter instruction (Read Processor Cycle Counter).

RSCC

Read System Cycle Counter: the OpenVMS PALcode call that firmware delay loops poll.

RTC

Real-Time Clock; see TOY.

Time-of-Year Clock (TOY)

RZ-series

DEC SCSI disk models (RZ26, RZ28, RZ29, ...).

SCSI Devices

SCB / SCBB

System Control Block: the table of exception and interrupt vectors; and its base register.

SCBL

SCSI Bus Control Lines.

SCSI Bus Control Lines

SCS

System Communications Services: the OpenVMS cluster messaging layer.

SCSI

Small Computer System Interface.

5.7 SCSI

SDE

PALshadow Register Enable: the field of the 21264's I_CTL register that switches in the PALshadow registers PALcode uses (21264 / EV67 HRM, I_CTL).

Firmware Decode & Decompression

SIA

Serial Interface Adapter: the 21143's 10 Mb/s physical-layer interface, controlled through CSR12-CSR15 (21143 datasheet).

DE500 Ethernet (21143 Tulip)

SMP

Symmetric Multiprocessing: more than one CPU sharing memory.

SMP (MultiProcessor) Design

SPAM

Set-Partitioned Associative Memory: EmulatR's TLB model. It can shard, but the ITB and DTB are instantiated flat at 128 entries, so as shipped they are fully associative.

Addressing & TLB

SRM

The Alpha console firmware (the >>> prompt) that EmulatR runs unmodified.

SRM Console

SROM

The serial ROM whose parameters seed the CPU at reset (passed in registers R16-R21).

SSOT

Single Source Of Truth: the one authoritative copy of a fact, from which every other copy is generated.

SYSTYPE / SYSVAR

The HWRPB system type and system variation fields, which identify the platform model.

Model Badging: SRM Platform Identity from an IIC Discriminator Device

TB / TLB

Translation Buffer / Translation Lookaside Buffer: the cache of virtual-to-physical mappings.

Addressing & TLB

TBIA / TBIAP

Invalidate every TB entry; invalidate every per-process TB entry.

TDF

Time Differential Factor: OpenVMS's offset from UTC, set during startup.

TIGbus

The 21272 chipset's bus for miscellaneous system logic: the flash ROM, and the interrupt inputs the Cchip polls eight at a time (21272 HRM 6.3).

Tsunami \ Typhoon

TOY

Time-Of-Year clock: the battery-backed date and time clock.

Time-of-Year Clock (TOY)

UART

The serial-port chip (16550-compatible) behind a serial port.

VAX

DEC's 32-bit architecture that preceded Alpha; Alpha supports its floating-point formats.

Floating-Point Considerations

VMB / SYSBOOT

The OpenVMS primary and secondary bootstraps; a conversational boot stops at SYSBOOT>.

VRT

Valid RAM and Time: the MC146818 bit that says the clock and its RAM are trustworthy.

Time-of-Year Clock (TOY)

Warp census

<stem>_warp.json: the firmware's calibrated delay loops, found on the first boot of a firmware image and collapsed on every later boot.

Warp, <firmware>_warp.json -- Calibrated-Delay Census
