Feature Matrix

Subsystem status as of August 2026. This reflects the DS10 / DS20 target, with ES40 in active bring-up; status evolves and should be reconfirmed against the current build.

 

Status vocabulary. Working: exercised by real firmware or a real guest and covered by tests. In progress: functional on the measured path, with named gaps still open. Planned: not implemented. A subsystem marked Working is faithful for the paths that have been exercised - it is not a claim of complete device coverage.

IDE / ATAPI virtual CD-ROM

In progress

dqa0 fixed disk enumerates and reads; ATA/ATAPI reset signatures and IDENTIFY are faithful. READ-ONLY and POLLED by design so far: there is no interrupt path (IRQ 14/15 are never driven), no write path (writes abort), and no DMA. Adequate for enumeration and console-era reads; not yet usable as a guest-OS system disk or install target.

IIC (PCF8584)

In progress

Sufficient for console bring-up on DS10 and DS20, including the discriminator device that yields the correct DS20 system badge. The bus runs POLLED (the completion interrupt is never enabled by firmware). The ES40 IIC decode base is unresolved and is likely an ALi M1543C SMBus rather than a fixed PCF8584 row.

Flash / NVRAM persistence

Working

Persists to <firmware>.rom / ds10_v7_3.rom; set and update srm survive across boots.

SCSI host adapter (NCR 53C810)

Working

The pka adapter is modeled at register level, including its SCRIPTS I/O processor: selection, bus-phase sequencing, message in / message out, DMA through the chipset address windows, and interrupt delivery. Register layout and the phase-mismatch recovery contract are verified against the DEC SRM console's own SCSI driver. Disconnect / reselection and tagged command queuing are deliberately not modeled yet.

SCSI disk and CD-ROM (dka)

Working

SCSI-2 target command set audited against ANSI X3.131-1994: INQUIRY, TEST UNIT READY, REQUEST SENSE with the UNIT ATTENTION state machine, READ LONG / WRITE LONG answering the ECC probe VMS runs on every boot (a wrong length is answered with VALID+ILI and the signed difference, so the initiator converges in one exchange instead of a retry ladder), READ CAPACITY, MODE SENSE / MODE SELECT with rigid-disk geometry pages, and READ / WRITE with range and write-protect checking. Genuine DEC drive identities (RZ28L / RZ29L / RZ40) carry documented geometry and capacity. Available on DS20 and ES40; DS10 is an IDE-only machine and has no SCSI bus.

boot / OS load

Working

An explicit boot dka0 loads the bootstrap from the SCSI disk and transfers control to it, and the automatic path is validated too: auto_action=BOOT with a persisted bootdef_dev carries a cold boot to the guest with no keystrokes (verified twice, 2026-08-20). boot_osflags is exercised by the conversational boots the crash-dump procedure uses.

Guest operating system (OpenVMS)

Working

OpenVMS Alpha V8.3 boots from the SCSI disk through a full (non-MIN) startup on DS20: the system disk mounts, QUEUE_MANAGER runs, DECnet and TCPIP start, and the boot reaches the login prompt - hands-off, with zero keystrokes from power-on (the console answers the firmware-update prompts and auto_action boots the default device). Login and an orderly SHUTDOWN run end to end. Certified 2026-08-20 under the integer-operate shadow checker: 6.0e9 cycles, boot to Username:, mismatches=0. Tru64 is untried. Installing an OS from CD media is not yet possible (G-29 / G-30).

 

Basis for these claims

"Faithful" and "verified" on this page mean checked against a primary source, not against expectation. The sources behind the storage and chipset rows are:

• ANSI X3.131-1994 (SCSI-2) - the target command set, sense data, and mode pages.

• NCR / Symbios 53C895 Data Manual, and the DEC SRM console's own SCSI driver sources - the adapter registers, its SCRIPTS processor, and the driver contract the adapter has to satisfy.

• EK-KZPBA-UG.B01 (KZPBA UltraSCSI adapter guide) - how a real DEC console renders drive identities.

• EK-SM2DR-PN.B01 (StorageWorks drive reference) - RZ28L / RZ29L / RZ40 geometry and capacity.

• The 21272 and 21264 hardware reference manuals - chipset registers and CPU behavior.

Per-claim verification, down to the clause or table and the line of code it was checked against, is recorded in the engineering audit records rather than here; this page is the summary they roll up to. Where a value could not be traced to a source it is called out as provisional rather than presented as fact.
