5.10 Platform Guides

EMulatR presents a specific AlphaServer model, not a generic Alpha. Each model has its own chipset, south bridge, device layout, console firmware and CPU count, and each behaves differently in ways that matter when you configure, boot and troubleshoot it. This section has one guide per model.

The memory default is what the launcher (tools/EMulatR_launch.sh) asks for when you give no size: 4 GB, clamped to the model's ceiling. The ceiling is the most the real machine supported; a larger request is clamped, with a message, rather than booting a machine that never existed.

 

Multiprocessor (SMP) support

Every model currently runs one CPU, including the DS20 and ES40, which support two and four. Running more than one CPU (SMP) is planned for release 2.3, with every CPU on one host thread so that a run stays deterministic and repeatable. A threaded mode, one host thread per CPU, follows in release 3.1. Each guide has a section on what SMP will mean for that model.

 

Consideration: Currently, SMP buys fidelity, not speed: OpenVMS runs its multiprocessor code paths, but with every CPU on one host thread each CPU gets a share of the same host time.
