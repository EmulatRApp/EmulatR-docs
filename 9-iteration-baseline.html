EMULATR_BLOCKEXEC

flag, default OFF, tier dev. Enables the block executor: straight-line decoded-descriptor runs execute from the block cache with boundary predicates at block exits. Certification pending (BRIEF-BLOCKEXEC-001); yields automatically to armed diagnostic instruments. Anchor: systemLib/Machine.cpp:1594.

EMULATR_BLOCK_MAX

integer, default 32, bounds 2..64, tier dev. Descriptor cap per block; delivery latency bounds at this many cycles. Registered tuning dial (SPEC-BATCH-001 §7.2): every measurement pins it explicitly; a release ships one frozen default. Anchor: pipelineLib/BlockCache.h:91.

EMULATR_BLOCKCACHE_BLOCKS 

integer, default 8192, min 256 (no code ceiling; rounded down to a power of two), tier dev. Block-cache frame count, the geometry dial. Anchor: pipelineLib/BlockCache.h:103.

The modulus pair (pre-existing, bounds added today)

 

EMULATR_IRQ_MODULUS

iinteger, default 1, bounds 1..524288, tier dev. Runs the IRQ-poll/interval-timer/delivery section once every N guest cycles instead of every retire (rounded up to a power of two, capped at the interval-timer period so a timer boundary is always a sweep boundary); device-interrupt latency becomes ≤N cycles. Cycle-keyed per Option C, coherent across a warp. Anchor: systemLib/Machine.cpp:2319.

EMULATR_TICK_CADENCE

iinteger, default 1, same bounds, tier dev. Measurement knob, not a tuning dial — the legacy retire-keyed P0-1 form, kept for reproducibility. Anchor: systemLib/Machine.cpp:2321.

The bounds paragraph (this closes JRN-V2-ENVBOUNDS-DOC-001's F-1)

 

Bounds and out-of-range values. The min/max shown for integer variables mirror the code's own clamp — the binary enforces, the registry documents. A value outside the range does not error and is not silently honored: it reverts to the code-defined bound. Per-variable shapes: EMULATR_IRQ_MODULUS/EMULATR_TICK_CADENCE round up to a power of two and cap at 524288 (0 becomes 1); EMULATR_BLOCK_MAX clamps into 2..64; EMULATR_BLOCKCACHE_BLOCKS floors at 256 and rounds down to a power of two, with no upper code bound.
