Platform Editor Troubleshooting

Message

Meaning and what to do

Open failed

The file could not be read. Check the path and that no other program has it locked.

Parse failed (offset n)

The file is not valid JSON; n is the byte where reading stopped. Fix it in a text editor, or restore the .bak.

Save failed -- Cannot write <file>

No write access to the file or folder, or the disk is full. The file on disk is unchanged.

Discard changes? -- Unsaved edits will be lost

Shown on Reload, Open or Quit with unsaved changes. Choose No and save first to keep them.

Required interface

That IIC device is one the emulator checks for; it cannot be deleted.

Bus full

The selected controller has no free address. Remove a unit, or put the device on another controller.

Not available -- virtual tape

Virtual tape is not yet supported; the editor does not add tape rows.

Not available -- only one device of this model

The emulator has one 53C810 and one DE500; a second row would share the first.

Rejected: <value> is not a hex value (0x...)

Status bar. The field needs a hex value written 0x....

The drive table (config/disk_types.json) was not found

Configure cannot offer drive models. Set PLATEDIT_DISK_TYPES to the file, or run the editor from the editors folder of an installed or run directory.

Configure: BLOCKED ... already exists

A new image would overwrite a file. Untick New to use the existing image, or choose another name.

Configure: not enough room for the new images

The disk folder's drive is short of space for all the new images together. Choose another folder or free space.

Configure: Nothing was added to the manifest

Finish failed; the message gives the reason and lists any images already created, which are left in place.

 

The emulator does not show a disk you configured

•Check the Issues pane for errors on that controller or unit.

•Check that the image is in the emulator's disk directory ([Storage] diskDir or EMulatR_DISK_DIR) and is at least the drive model's size.

•Check the emulator's log for lines starting Storage:; they say why a unit was not attached.

•If the log says it is using the built-in default DS10 bus, the manifest failed the emulator's checks: open it in the editor and fix every error.
