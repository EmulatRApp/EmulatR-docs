Platform Memory Reference

This appendix records the vendor memory specifications for the AlphaServer models EmulatR models or plans to model: how much memory each chassis physically holds, how its memory subsystem is organized, and where each figure came from. The maximum-memory column is the basis for EmulatR's per-model silicon clamp; what the clamp does, and when it applies, is described in Platform Identity & Memory Geometry rather than here.

The vendor figures are quoted in GB as the source documents write them. EmulatR implements each ceiling as the binary equivalent -- a 2 GB DS10 is clamped at 2147483648 bytes -- which is the reading these memory specifications intend.

 

DS15 / DS15a

Maximum memory is 4 GB. The DS15 is built around the single-CPU Alpha 21264C (EV68C) platform architecture, and uses standard error-correcting code (ECC) memory configurations, reaching its maximum via 1 GB DIMM modules.

 

DS20 / DS20e

Maximum memory is 4 GB. DS20 is a Tsunami (21272) box; EmulatR models the ceiling as four 1 GB banks.

 

DS25

Maximum memory is 16 GB across 16 DIMM slots, on the Titan (21274) chipset.

This figure is the one EmulatR already applies, and it is consistent with the chassis slot count, but it is the one entry in this appendix with no named source document behind it -- the reference set that supplied the other platforms grouped DS25 under a DS20 heading without giving it a separate maximum. Treat the 16 GB as sound but uncited until a DS25 QuickSpec is attached.

 

ES40

The ES40 ships in two memory builds. Model 1, the entry-level configuration, holds up to 16 GB across 16 DIMM slots on its memory motherboards. Model 2, the expanded configuration, holds up to 32 GB across 32 DIMM slots, at 8 DIMMs per memory motherboard.

The memory subsystem is built on a switch-based interconnect driven by a chipset of one C-chip (command), eight D-chips (data paths) and two P-chips (PCI interface). It carries two 256-bit memory buses supporting multiple memory arrays, which yields high-bandwidth interleaving of up to 5.2 GB/sec.

EmulatR clamps ES40 at the Model 2 figure of 32 GB. That bounds the more capable build, so a Model 1 machine modeled under the same name is not protected by the clamp at its own 16 GB ceiling.

 

ES45

Maximum memory is 32 GB, using up to 32 DIMM slots across 8 memory options and arrays.

The ES45 design is an evolution of the mid-range enterprise architecture and supports up to four high-speed EV68CB processors. It incorporates dual memory buses operating in a multi-way interleaved configuration -- up to 4-way interleaving when the arrays are equally populated -- to lower latency and maximize throughput. Memory options are structured in groups of 4 DIMMs per kit; the MS620 kits range from 512 MB up to 4 GB in capacity.

 

DS10

Maximum memory is 2 GB across the Webbrick's 4 DIMM slots. The DS10 figure predates this reference set and is carried here so the summary table covers every modeled platform.
