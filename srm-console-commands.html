SRM Console Commands

EMulatR runs the real HP SRM console firmware, so the console prompt accepts the firmware's own commands, exactly as on an AlphaServer. This page lists every command the ES40 console (67CLIPPER V7.3-1) offers, as reported by its own help command under EMulatR, with examples captured from EMulatR on 29 September 2026.

 

The DS10 and DS20 consoles (V7.3-2) offer nearly the same set; type help at their prompt for their list.

 

The prompt

•Multiprocessor consoles (DS20, ES40) prompt P00>>> (the number is the CPU); the DS10 prompts >>>.

•The prompt appears when the console has finished power-up, and again when the operating system halts or you press Ctrl/P.

•Commands may be shortened where unambiguous; e (examine) and b (boot) are used throughout this guide.

•Environment variables you set are kept in the console's flash, which EMulatR saves in firmware/<stem>.rom on a clean shutdown.

 

Reading the synopses

Each synopsis below is printed by the firmware. Its conventions (from help help):

Notation

Meaning

<item>

A value you supply.

<item>...

One item or a list of them.

[ ]

Optional.

{a,b,c}

Exactly one of a, b, c.

{a|b|c}

Any combination of a, b, c.

 

Examining and depositing

examine (e) reads memory or a register; deposit writes one. The address takes a device prefix: pmem: physical memory, vmem: virtual memory, gpr integer registers, fpr floating-point registers, ipr processor registers, or a register name such as r0, pc or ps.

 

Options: -b -w -l -q data width, -n <count> repeat, -d disassemble.

P00>>> examine -n 3 pmem:8000

pmem: 8000 C3402E1E47FF0410

pmem: 8008 0004000100010162

pmem: 8010 0000000000000000

pmem: 8018 0000000000000000

P00>>> examine -d pmem:8000

pmem: 8000 47FF0410CLR R16

P00>>> e r0

gpr: 0 ( R0) 0000000000018000

P00>>> e ps

ipr: 17 ( PS) 0000000000001F00

deposit writes to the halted machine; for example deposit sirr e requests an IPL 14 software interrupt, which is how XDELTA is entered on a running system. Anything deposited takes effect when you continue.

 

Environment variables

show * lists them all; show <name> shows one; set <name> <value> changes one; clear <name> removes it.

P00>>> show auto_action

auto_action HALT

P00>>> show os_type

os_type OpenVMS

P00>>> show version

version V7.3-1 Feb 27 2007 12:57:47

Common settings: set auto_action boot (boot bootdef_dev at power-up), set bootdef_dev dka200, set boot_osflags 0,0, and on the network adapter set ewa0_mode FastFD.

Booting and control

Command

Example

What it does

boot

b dka200 -flags 0,0

Boot a device. -flags passes root and boot flags to the operating system (see Guest Boot and Debugging OpenVMS with XDELTA).

continue

continue

Resume the halted operating system.

halt

Halt a processor.

start

Start a processor at an address.

crash

Force the operating system to crash and write a dump.

initialize

init

Re-initialise the console. Known issue: under EMulatR this does not reset the machine; after an OpenVMS halt, stop and restart EMulatR for a clean boot.

 

Console processes and utilities

The SRM console is a small multitasking system of its own, with a shell, pipes and a file system over devices.

P00>>> uptime

hello

ls lists the console's commands and devices; cat, grep, more, wc and hd work as on UNIX. eval evaluates a postfix expression (eval 10 + 10 fails with expression evaluator underflow).
