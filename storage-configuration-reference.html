Storage Configuration Reference

Every setting that controls the storage engine lives in the platform manifest (<model>_v7_3_platform.json in the run directory, for example ds20_v7_3_platform.json). Machine-wide keys sit at the top level; per-disk keys sit on a storage row under a PCI device. The Platform Editor validates all of them against the platform schema.

 

Machine-wide keys

Key

Values

Default

Meaning

storage_engine

direct, pool

direct

Which engine serves writable disks. CD, ISO and host-passthrough media always use the direct engine.

pool_mb

1 - 1048576

512

Size of the resident buffer pool, in MB. Pool engine only.

max_pending_mb

1 - 65536

64

Bound on data waiting in the ordered write queue. A full queue delays the next guest write (wall time only). It also bounds the size of the dump.

pool_dump_path

host path

empty

Pool dump file, preallocated at start. Must be on a volume holding no writable image. Empty means no dump: an orderly abort is then refused, and queued writes are lost if the pool closes while paused.

 

Per-disk keys (storage row)

Key

Values

Default

Meaning

write_cache

off, ordered

off

off: a write completes when it is durable (write-through). ordered: a write completes from memory and drains in guest order -- experimental. Writable disks only.

cache_min_mb

1 - 65536

1

Minimum residency for this disk. Must hold one maximum-size transfer (128 KB).

cache_max_mb

0 - 65536

0

Maximum residency for this disk. 0 means no per-disk cap. Must not be below cache_min_mb.

 

The per-disk keys and pool_mb / max_pending_mb are marked provisional in the schema: their names and ranges may still change.

 

Rules checked at start

•pool_mb must be greater than max_pending_mb plus the sum of every pooled disk's cache_min_mb.

•A pooled image must be a whole number of 4 KB pages, and its volume's sector size must divide 4 KB.

•pool_dump_path must not share a volume with any writable image.

•A dump file holding a pending dump refuses the pool.

When a check fails, the affected disk (or every disk, if the pool itself cannot start) falls back to the direct engine, with an ERROR in the run log giving the reason.

 

Fixed parameters

These are built in, not manifest keys:

Parameter

Value

Meaning

Page size

4 KB

Pool granularity; eight guest sectors.

Maximum transfer

128 KB

Largest single guest request per disk.

Host-call limit

15 s

A host read or write that takes longer is declared hung.

Retry window

30 s

Total time a failed write is retried before the writer pauses.

Retry backoff

10 ms doubling to 2 s

Delay between retries.

Coalescing cap

64 pages (256 KB)

Largest host write the writer builds from one guest write.

Memory locking

on

Large pages or VirtualLock when the privilege allows; pageable memory otherwise.

 

Example

Pool engine with a dump on a second volume; one disk in the default write-through mode and a larger residency floor:

 "pool_mb": 1024,

 "max_pending_mb": 64,

  "pool_dump_path": "F:/EMulatR_scratch/ds20_pool.dmp",

 "pci_devices": [

 "model": "RZ29L", "media": "dka0.vdisk", "media_kind": "image",

Where the images come from

The engine does not change how image paths resolve. A relative media path resolves against the configured disk directory ([Storage] diskDir, which can be steered per run with EMulatR_DISK_DIR); an absolute path is used as-is.

 

What the run log shows

•Storage: storage_engine = pool (512 MB pool, max_pending 64 MB, dump '...') -- the pool started.

•Storage: '<image>' served by the POOL (disk N, write_cache off) -- one line per pooled disk.

•Storage: SCSI disk '<image>' -- storage_engine = pool attach FAILED (<reason>); this disk uses the DIRECT path -- a fallback.

•Storage: '<image>' write_cache = ordered is EXPERIMENTAL ... -- a warning for each ordered disk.

•Storage: pool at shutdown -- drained; ... -- the shutdown statistics.

 

Platform Editor

The editor validates these keys against the schema today. A radio button for storage_engine (direct / pool) is planned; until it lands, set the key in the manifest.
