Platform Editor Validation Messages

The editor checks the manifest after every change and on Tools > Validate. Each finding has an Id, a severity and a message, and selecting it in the Issues pane selects the item. An error means EMulatR would reject the manifest or not run the device as written; fix errors before running the system.

 

Id

Severity

Check

V-01

error

Two PCI devices at the same hose/bus/slot/function (numbers compare by value: 1 and 0x1 are the same).

V-02

error

Two IIC devices at the same address.

V-03

warning

Two items in one list with the same name.

V-04

error

Two storage units at the same channel and unit on one controller.

V-05

warning

An IIC address that is not a hex value.

V-06

error

An odd IIC address (the emulator rejects the manifest).

V-07

warning

A PCI device's identity differs from the catalog's value for its model.

V-08

information

A PCI model the catalog does not know.

V-11

information

A comment marked _PROVISIONAL.

V-15

error

An invalid PCI vendor id (not hex, 0x0000 or 0xFFFF).

V-25

error

A SCSI unit at the controller's own id (the initiator, 7 by default).

V-26

error / information

A SCSI unit on a channel with no channels[] entry (information when the controller has no channels[] at all).

V-27

error

A SCSI target above 7 on a narrow bus. A 53C810 is always narrow.

V-28

error

Two channels[] entries with the same index.

V-44

error

A model the emulator has only one of (53C810, DE500, the IDE and ISA bridge functions) used by more than one row.

V-45

error

A tape row. Virtual tape is not yet supported: the emulator would read the row as an ATAPI CD-ROM, or reject the whole manifest.

V-46

error

A mac that is not six hex pairs (08-00-2B-E5-40-00 or with colons), or is a multicast address.

V-47

warning

A MAC address that another manifest in the same folder also uses.

V-48

error

An IDE channel/unit used under two IDE controllers, or a second ATAPI CD-ROM. EMulatR has one IDE space and one ATAPI CD-ROM device, whichever IDE controller a unit is listed under.

V-49

warning

A PCI device at a hose and slot the platform's board does not provide (board description).

Note: When the emulator rejects a manifest at start-up it does not stop: it logs a warning and runs its built-in DS10 device set instead. A manifest with errors therefore does not give you the system you configured.
