5.7 SCSI

SCSI is the bootable storage path. The IDE / ATAPI channel exists so the firmware can enumerate a disk and a CD-ROM; the guest operating system lives on a SCSI disk, and it is dka0 that an OS boot actually reads from.

 

What EmulatR models

The adapter is an NCR 53C810 PCI SCSI host-bus adapter -- the DEC KZPAA option -- which the console enumerates under the device prefix pka. Behind it sit SCSI-2 targets: a virtual disk (dka) and a virtual CD-ROM, each backed by a host file through a common block-media layer.

 

The 53C810 is not a register-poking adapter. It is SCRIPTS-driven: the console driver downloads a SCRIPTS program, writes its entry point to DSP, and the on-chip processor executes that program itself, fetching its own instructions and moving data blocks as a PCI bus master. Those fetches and block moves reach guest memory through the Pchip DMA window, exactly as the real card's would.

 

Why the transfer looks synchronous

The SRM console's driver is synchronous by design: it writes DSP, the chip runs until it raises an interrupt, and the interrupt service routine re-kicks it through DCNTL<STD>. EmulatR matches that contract by running the SCRIPTS program to completion inside the DSP / STD write rather than stepping it across cycles. The guest cannot tell the difference, because the guest never observes the chip mid-program -- it observes an interrupt and a result.

 

Where the SCSI path stands

The adapter, the drive identity and capacity, and the sense / attention path are modeled and audited against the DEC sources. OpenVMS Alpha V8.3 boots from the SCSI disk to its banner reliably on the DS20, and its drivers initialize.

 

The system disk goes VALID, the volume mounts, and the boot reaches the DCL login prompt on the DS20. The virtual CD-ROM also lags its disk sibling on shared protocol behavior -- it raises no UNIT ATTENTION at all, so a media change is invisible to a running guest, and pending sense is not cleared by an intervening successful command.

 

Those rows are carried in Known Gaps, which is the current record for what is missing rather than this page.
